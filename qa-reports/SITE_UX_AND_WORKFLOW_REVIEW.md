# مراجعة تجربة الموقع والمودالات

بدأت المراجعة بتجربة تسجيل مورد جديد، ثم تابعت إجراءات مراجع الطلب، وعروض المورد، والعطاءات، ومساحات التقييم والإدارة. صُممت الأيقونات بجانب السجلات لفتح القسم المرتبط بها من أول نقرة.

| الواجهة | ما تغيّر |
| --- | --- |
| تسجيل المورد | ثلاث مراحل ظاهرة: بيانات الشركة، المستندات، حالة الطلب. تُعرض الفئات كبطاقات قابلة للاختيار مع عدّاد مباشر. الرفع يوضّح الأنواع وحالة كل نوع، ويعرض الملفات المحددة مع الحذف قبل الإرسال والتحقق من العدد والحجم. تظهر رسالة واضحة عند محاولة المتابعة قبل إرفاق أي مستند. |
| لوحة المورد | أيقونتان مستقلتان لحالة الطلب ومستنداته. يمكن للمورد قيد المراجعة فتح نموذج الرفع من واجهته. |
| عروضي | أيقونات مستقلة للملخص، الأسعار، المستندات، والتقديم. إضافة السعر أو رفع المستند يعيدان المستخدم إلى القسم المفتوح ويحدثان بياناته مع إبقاء رسالة نتيجة الحفظ. |
| دليل الموردين | الملخص والمستندات منفصلان، وكذلك تعديل الفئات وقرارات الاعتماد والتفعيل والرفض والتعليق حسب الدور والحالة. |
| مسؤول التوريد | لكل عطاء أيقونات للملخص، جولات التقديم، QR، والدعوات. أصبحت جولات التقديم بطاقات تعرض الأوقات والنتيجة وسبب إعادة الفتح. يظل جدول المقارنة جنبًا إلى جنب حيث يخدم عمل المراجع. |
| الإدارة | من سجل العطاءات يمكن فتح الملخص واللجنة والدعوات والعروض أو QR مباشرة. سجل العروض يفتح ملخص العرض أو بنوده. |
| التقييم واللجنة العليا | أيقونات لتقدم المراجعين، المقارنة الموزونة، والتقرير والقرار. الشاشة التي تعرض القرار تركز على التقرير والإجراء المتاح. |
| التصميم المشترك | وُحّدت المسافات وقراءة العناوين وطريقة عرض حقول النماذج والملفات. حركة ظهور قصيرة عند الانتقال، وتأثيرات على الأيقونات والحقول وأقسام المودالات، مع احترام تفضيل تقليل الحركة. |

تظل روابط التفاصيل المباشرة تعرض السجل الكامل. المودالات المختصرة تستخدم نفس مسارات وصلاحيات الخادم، وملفات PDF تُفتح أو تُنزّل بالطريقة المعتادة.

جولة المتصفح شملت فتح روابط الأشرطة الجانبية للأدوار المشمولة على عرض 390 بكسل. راجعت أيضًا لقطات التسجيل والرفع ومودالات العرض والتقييم. ظهر في الجولة الأولى أن رسالة تحقق الرفع بقيت ظاهرة بعد اختيار ملف صالح؛ عُدلت لتزول عند تصحيح الحقل. صححت كذلك صياغة محدد JavaScript في اختبار مودال التقديم؛ أكملت الجولة التالية التحقق باستخدام محدد آمن.

تغطية المتصفح مشروطة بالبيانات المتاحة في قاعدة الاختبار؛ لم تُفتح كل حالة شرطية لكل نموذج. بقيت المقارنات المتقابلة وطباعة ملفات PDF والعمليات التي تحتاج ملفات أو أجهزة فعلية ضمن مساراتها الحالية.

نجح بناء Release ونجحت الاختبارات الـ64. شملت المجموعة 22 حالة Chrome ناجحة بلا أخطاء JavaScript غير معالجة. تحقق الاختبار من حفظ فئتين ومستند واحد للمورد الجديد، ثم اعتماد الطلب من مسؤول التوريد وإضافة دور المورد. كما مرّت الجولات، والتقييم، والترسية، والإلغاء وإعادة الطرح على قاعدة LocalDB مؤقتة.
