# إصلاحات المرحلة الرابعة

**B16 — البحث الصوتي في طلباتي.** لم تعد الصفحة تعرض زر البحث أو تحمّل ملفه، وكان الملف يربط أحداثه مرة واحدة عند تحميل المستند. أُعيد الزر مع منطقة حالة قابلة للقراءة، وبقي البحث النصي متاحًا. يستمع السكربت إلى `workspace:load` ويربط كل عنصر جديد مرة واحدة؛ ويتجاهل النتائج بعد فصل النموذج. تحقق BR05 في Chrome من بدء محاكاة التعرف مرة واحدة لكل نقرة بعد انتقالين عبر AJAX. المحاكاة لا تختبر الميكروفون أو دقة التعرف.

**إعداد الاختبار.** كان ربط المتصفح بعنوان IP ينتج خطأ نطاق WebAuthn؛ استُبدل بعنوان localhost على نفس مستمع Kestrel. كما انتظر المشغّل اكتمال تحميل سكربت المصادقة بعد تسجيل الخروج. لم يُعدّل كود المصادقة أو السياسات لهذا السبب.

ملفات التطبيق المعدلة: `Views/PurchaseRequisitions/Index.cshtml` و`wwwroot/js/department-request-voice-search.js`. أضيف `BrowserReleaseTests.cs` ومشغّل `phase4-browser.mjs` والأدلة والتقارير. لا ترحيل جديد ولا تعديل لبيانات المشروع.
