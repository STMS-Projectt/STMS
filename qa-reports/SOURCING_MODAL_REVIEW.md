# مراجعة مودالات مسؤول التوريد

النطاق: لوحة التوريد وسجلات الطلبات والعطاءات والدعوات والامتثال والتقييمات والاستفسارات، بما فيها الإجراءات الفرعية التي تُعرض داخل نافذة العمل نفسها.

| المسار | المراجعة والتغييرات |
| --- | --- |
| مراجعة طلب الشراء | إطار موحّد لعرض تفاصيل الطلب وإجراءات المراجعة؛ الانتقال إلى الاستفسار داخل النافذة مع الرجوع إلى الطلب. |
| تفاصيل العطاء | عرض أوسع للتفاصيل؛ مراجعة فتح التعديل ومعايير التقييم من التفاصيل والعودة إليها. |
| إنشاء وتعديل العطاء | عنوان وإرشاد موجز وبطاقة نموذج واضحة، ومسافات بين الحقول والإجراءات. |
| معايير التقييم، تعيين اللجنة وإعادة فتح الجولة | عناوين متناسقة، نموذج داخل بطاقة، وتمييز الإجراء الفرعي في رأس النافذة. |
| سجل الدعوات والتفاصيل والإنشاء | مربعات اختيار واضحة داخل بطاقات يمكن الضغط عليها كاملة، مع زر إلغاء وإرسال منفصلين. |
| الامتثال وقرار عدم المطابقة | عرض واسع للجدول المقارن مع تمرير داخل حدوده، ونموذج قرار واضح وإمكانية العودة إلى المقارنة. |
| التقييمات والاستفسارات | إطار متسق مع بقية نوافذ التفاصيل، مع الحفاظ على الإجراءات المرتبطة بالسجل. |
| نوافذ التأكيد | تنسيق مشترك لأزرار التأكيد والإلغاء وتحسين تباين النص. |

## السلوك المشترك

تظهر إشارة «Related action» عند فتح نافذة فرعية. تتغيّر مساحة النافذة حسب نوع المحتوى وتبقى الأزرار قابلة للالتفاف على الشاشات الصغيرة. حركة الانتقال قصيرة وتحترم إعداد تقليل الحركة. تبقى روابط الملفات خاضعة لقواعد التنزيل الحالية.

## التحقق

نجح بناء Release وفحص صياغة JavaScript وفحص المسافات في التغييرات. أُضيفت تغطية Chrome لفتح تفاصيل العطاء وإجراءاته الفرعية، وفتح الدعوات والامتثال والتقييمات وفحص الرجوع.

## ملاحظات الجولة الثانية

- كشفت الجولة الأولى فشل فتح تفاصيل الدعوة لأن صفحة العرض تحتاج بيانات العطاء والمورد، ولم يكن الاستعلام يحمّلهما. أُضيف تحميلهما صراحة وأُعيد تصميم صفحة الدعوة ببطاقة معلومات واضحة.
- أظهرت لقطات تفاصيل العطاء امتداد قائمة الحقول عموديًا. استُبدلت بشبكة معلومات، وطُوي نص الشروط داخل قسم قابل للتوسيع.
- حُفظت لقطات Chrome لعرض العطاء ونموذج التعديل الفرعي في مجلد `phase4-browser-evidence`.
- أُعيد فحص لقطات العطاء والتعديل وقرار عدم المطابقة بعد إصلاح العرض. تعذّر اعتماد نتيجة التشغيل الثاني كاملة لأن Windows رفض كتابة ملف نتائج Chrome القديم عند نهاية التشغيل. أُضيف خيار مجلد نتائج مستقل لتفادي هذا التعارض.
- نجحت إعادة فحص Chrome في مجلد النتائج المستقل: 20 حالة ناجحة، بلا إخفاقات. شمل ذلك مودال مراجعة الطلب والاستفسار الفرعي، العطاء والتعديل والمعايير، الدعوات، الامتثال وقرار عدم المطابقة، تعيين اللجنة، التقييم وإعادة فتح الجولة. فُحصت بصريًا لقطات العطاء والتعديل وعدم المطابقة؛ بقية الحالات تحقّق منها الاختبار الوظيفي.

## دليل الموردين لمسؤول التوريد

أضيف رابط Supplier Directory في الشريط الجانبي. يستطيع مسؤول التوريد عرض الطلب والفئات وفتح المستندات، والموافقة على المورد قيد المراجعة أو إعادة تفعيل المورد الموقوف بعد وجود مستند داعم. يُحدّث القرار حالة الطلب وصلاحية حساب المورد ويُسجّل في سجل التدقيق. الرفض والإيقاف وتعديل الفئات تبقى للمدير.

نجحت مجموعة تكامل SQL المكوّنة من 15 حالة، بما فيها عرض المورد لمسؤول التوريد، منع الموافقة دون مستند، منح دور المورد، إعادة التفعيل، ومنع الإيقاف من حساب مسؤول التوريد. هذه الإضافة اختُبرت عبر HTTP وقاعدة مؤقتة؛ جولة Chrome ذات العشرين حالة تخص مراجعة المودالات التي سبقت الإضافة.
