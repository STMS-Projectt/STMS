# جاهزية الإصدار النهائية

**غير جاهز للإصدار؛ صالح لعرض أكاديمي محدود بمسارات مثبتة، باستخدام بيانات اصطناعية.** لا تعتمد نتيجة اختبار HTTP وحدها بوصفها تحققًا من تنفيذ دورة العطاء من واجهة المتصفح.

- المثبت: ترقية SQL Server LocalDB في بيئات اصطناعية فارغة ومن مخطط سابق، اختبارات الأدوار الأساسية ومفاتيح المرور بمُصدّق Chrome افتراضي، بعض نوافذ القسم، وانحدار مسارات التصويت والإلغاء في HTTP وSQL.
- المطلوب قبل أي إصدار: تنفيذ A وB وC كاملة في المتصفح، التحقق من صلاحيات العزل عبر حسابات متعددة لكل دور، اختبار كل النوافذ والملفات والواجهات الرئيسية، وفحص إمكانية الوصول. اختبر ترقية نسخة معزولة من بيانات حقيقية منقحة بعد توفيرها، مع نسخة احتياطية وخطة رجوع.
- مطلوب قرار أعمال بشأن رفض المدير أو إرجاع التقرير قبل تصويت اللجنة، والتقارير القديمة التي لا تحتوي سجلات تسليم، ومقارنة عروض متعددة العملات. لا تغير هذه المرحلة السياسة.
- FaceLab تجربة معطلة افتراضيًا وليست دخولًا مستقلًا بالوجه. لا تحقق لمزوّد الوجه الحقيقي أو كاميرا وعتاد حقيقيين. لم يُستخدم مزود مدفوع.
- الاختبارات المتبقية تشمل Ollama، تحققًا من محتوى PDF وQR والتوقيع والختم المائي والتصدير، الميكروفون الفعلي، وفحص WCAG 2.2 AA.
